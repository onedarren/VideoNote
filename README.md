# VideoNote —— 把一条视频，变成一份能用的笔记

> 粘贴一个视频链接，60~90 秒后，得到一份**带时间戳、带关键帧截图、能提问、能导出**的结构化笔记。
> 支持 B 站、YouTube、抖音、快手、小红书、微博、TikTok，也支持本地视频文件。
> Windows 桌面端 + Android 手机端。

VideoNote 要解决的，就是这件事。

## 它做了什么

一句话：**把视频变成一份你可以搜索、可以翻阅、可以引用、可以带走的笔记。**

```
一个链接 或 一个本地视频
        ↓
   60 ~ 90 秒
        ↓
一份结构化笔记（含章节 / 要点 / 关键帧截图 / 时间戳）
        ↓
  可提问 · 可导出 · 可归档
```

不是简单的"语音转文字稿"——那只是把一小时视频变成一小时文字，同样难读。

VideoNote 产出的是**重新组织过的内容**：分了章节、提炼了重点、保留了关键画面、每一段都能点回原视频的对应时刻。

## 核心功能

### 一、输入：什么都能喂进去

| 能力 | 说明 |
|---|---|
| 多平台链接 | B 站 / YouTube / 抖音 / 快手 / 小红书 / 微博 / TikTok/支持超过1000+平台，长短链接自动识别 | 
| 本地视频文件 | MP4 / AVI / MKV / MOV 直接导入，支持多选批量 |
| 批量处理 | 一次粘贴多个链接，排队自动处理，适合课程系列 |
| 登录可见内容 | 部分平台需登录，扫码一次即可，不用反复折腾 |

**本地视频导入是个被低估的能力**：会议录屏、内部培训录像、自己录的教程、网课下载的本地文件——这些从来没有公开链接的内容，同样可以处理。

### 二、生成：笔记按你要的样子组织

**4 种笔记结构**

| 结构 | 适合场景 |
|---|---|
| 结构化笔记 | 通用，章节 + 要点 + 思维导图 + 总结，最常用 |
| 大纲式 | 课程、教程，层级清晰便于复习 |
| 思维导图 | 梳理逻辑脉络，适合分享和汇报 |
| 时间线 | 会议纪要、访谈、长对话，按发生顺序记录 |

**9 种表达风格**：均衡 / 学术 / 口语 / 重点提取 / 详细 / 精简 / 技术 / 叙事 / 要点罗列。

同一个视频，给老板看用"精简"，给团队看用"详细"，自己复习用"要点罗列"——**同一份内容，换个风格重新生成即可，不用重新处理视频**。

**两个细节让它真正好用**：

- **关键帧自动截图**：说到 PPT、表格、代码、白板时，对应画面会自动截取并插进笔记
- **时间戳跳转**：笔记每个段落都能点回原视频的对应时刻，方便核对和引用

### 三、问答：直接对着笔记提问

笔记生成后，右侧是问答面板。你可以直接问：

- "作者对这个问题的结论是什么？"
- "第 3 节提到的三个步骤，能不能展开讲讲？"
- "整篇里有哪些可以直接落地的建议？"

**答案会标注引用来源**，告诉你结论出自笔记的哪一段（进而可以追溯到视频的哪一分钟），而不是凭空生成。所有问答记录都会保留，下次打开接着聊。

这个功能把笔记从"静态文档"变成了"可以对话的资料"。复习时不用通篇重读，直接问就行。

### 四、导出：6 种格式，交付即用

| 格式 | 用途 |
|---|---|
| Markdown | 标准 .md，兼容 Obsidian / Notion / Typora，继续编辑 |
| Word | 打印、提交作业、工作汇报 |
| PDF | 中文排版完整，适合归档和传阅 |
| 思维导图 | 矢量图，放大不失真 |
| 图片单文件 | 整篇笔记内嵌为一张长图，一键发微信 / 钉钉 / 飞书 |
| 纯文本 | 最小体积，粘贴到任何地方 |

**"图片单文件"值得单独说**：在微信里给别人发一份笔记，发文件可能被拒、对方未必装了对应软件，但一张长图谁都能看。这是很多人实际用得最多的一种。

### 五、沉淀：个人知识库

笔记会不断累积，VideoNote 提供了让它"用得起来"的管理能力：

- **版本管理**：同一个视频的多次生成结果都保留，可对比、可回退
- **标签管理**：按主题、来源、项目打标
- **多选聚合**：把若干篇笔记合并成一份综合资料
- **全文搜索**：关键词直接搜到某条笔记的某一段

用完就扔的笔记没有价值，能被再次找到的才有。

### 六、隐私：数据在自己手里

- **完全在本机运行**，视频和笔记不上传第三方服务器
- **断网仍可使用**（7 天容错），出差、飞行途中照常工作
- **授权绑定账号**，换电脑重新登录即可，不丢失使用记录

对处理内部会议录屏、未公开课程、涉密培训材料的人来说，这一条可能比所有功能加起来都重要。

## 常见问题

**Q：视频必须公开吗？**
不需要。本地视频文件可以直接导入；需要登录才能看的平台内容，扫码登录一次即可。

**Q：外语视频能处理吗？**
可以，支持自动识别与中英双语字幕。

**Q：断网了还能用吗？**
可以。完全在本机运行，断网状态下仍可正常使用（7 天容错）。

**Q：换电脑数据会丢吗？**
授权跟随账号，换电脑重新登录即可继续使用。笔记数据保存在本机，建议定期导出备份。

**Q：一份笔记不满意，能重新生成吗？**
可以。所有生成记录都会保留版本，可对比、可回退，也可以换个风格重新生成（不需要重新处理视频）。

**Q：年卡和永久卡怎么选？**
如果你打算长期用（比如一个学期、一个项目周期），年卡最划算；如果确定会一直用下去，永久卡一次买断更省心。**不确定的话，先买月卡试用**——全部功能都一样，先验证它是否真的适合你。

**Q：支持退款吗？**
卡密兑换前可联系客服退款；兑换后因授权属于数字商品，不支持退款。建议先试用再购买。
